## 🎯 Mission

Mettre en œuvre un environnement **Windows Server** complet : services d’infrastructure, stratégies de sécurité, supervision et droits d’accès.

---

## 🛠️ Stack

- **OS** : Windows Server
- **Services** : AD DS, DNS, DHCP, GPO
- **Monitoring** : PerfMon / alertes
- **Sécurité** : durcissement, audits, modèles de sécurité

---

## ✅ Points clés

- Implémentation et test de services d’infrastructure
- Application de stratégies de sécurité
- Supervision et remontée d’alertes
- Documentation d’exploitation
