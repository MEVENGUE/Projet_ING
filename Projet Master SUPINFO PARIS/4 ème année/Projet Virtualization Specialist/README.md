## 🎯 Mission

Concevoir une infrastructure virtualisée complète pour **NovaSys**, avec focus sur la **haute disponibilité**, la segmentation réseau et la sauvegarde.

---

## 🛠️ Stack

- **Hyperviseurs** : VMware / Hyper-V / VirtualBox
- **Stockage** : datastores, snapshot
- **Réseau** : VLAN, NAT, règles de pare-feu virtuel
- **Sauvegarde** : stratégie de backup et tests de restauration

---

## ✅ Points clés

- Plan d’adressage et segmentation
- Templates de VM et politique de snapshot
- Plan de sauvegarde et tests de PRA
- Documentation d’exploitation
