## 🎯 Mission

Concevoir une architecture **cloud résiliente et sécurisée** sur AWS en suivant les bonnes pratiques du programme AWS Academy.

---

## 🛠️ Stack

- **Cloud** : Amazon Web Services
- **IAM** : rôles, politiques, moindre privilège
- **Réseau** : VPC, subnets, NAT Gateway, Security Groups
- **Compute** : EC2, Auto Scaling
- **Stockage** : S3 / EBS

---

## ✅ Points clés

- Design multi-AZ avec haute disponibilité
- Sécurité périmétrique et gestion des identités
- Optimisation des coûts et automatisation du provisioning
