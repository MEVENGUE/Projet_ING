## 🎯 Mission

Concevoir et sécuriser une infrastructure Linux orientée **entreprise critique** : hardening, supervision, sauvegarde, plan de reprise.

---

## 🛠️ Stack

- **OS** : RHEL / Ubuntu Server
- **Hardening** : `auditd`, SELinux/AppArmor, `ufw` / `firewalld`
- **Monitoring** : Prometheus + Node Exporter
- **Backup** : `rsync`, `borg`, sauvegarde externalisée
- **PRA** : Procédures de bascule et tests de reprise

---

## ✅ Points clés

- Sécurisation des accès (SSH, MFA, sudoers)
- Journalisation centralisée et détection d’anomalies
- Plan de sauvegarde chiffré + rétention
- Tests de failover documentés
